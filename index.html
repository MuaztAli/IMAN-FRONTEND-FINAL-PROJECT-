Frequently Asked Questions

Got questions? We've got answers.

What is the Frontend Track?

+

The Frontend Track is an immersive training program teaching you how to design and build user interfaces using HTML5, CSS3, and JavaScript.

Do I need previous coding experience?

+

No prior experience is necessary! We start from absolute zero, covering basic computer navigation up to advanced asynchronous JavaScript.

Are frameworks like React or Tailwind used?

+

No. This track focuses strictly on vanilla HTML, CSS, and JavaScript to build a rock-solid foundation before moving on to frameworks.

How long does the bootcamp last?

+

The track runs for several intensive weeks, featuring live sessions, hands-on coding labs, and portfolio project submissions.
