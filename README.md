# IMAN Bootcamp - Frontend Track Website

A responsive website for the IMAN Bootcamp Frontend Track showcasing curriculum, student projects, FAQ, and registration.

## 🛠️ Technologies
- HTML5 | CSS3 (Grid, Flexbox) | JavaScript (DOM)

## ✨ Main Features
- Fully responsive layout (Mobile, Tablet, Desktop)
- Mobile navigation menu (Hamburger toggle)
- Interactive FAQ accordion
- Curriculum/Project filtering by category
- Registration form with validation
